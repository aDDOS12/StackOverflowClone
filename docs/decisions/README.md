# Architecture Decision Records

This folder records significant architecture decisions made in this project, using a lightweight format based on Michael Nygard's ADR template.

Accepted records are not edited. If a decision changes, a new ADR is added and the old one is marked as superseded.

| ADR | Title | Status |
|---|---|---|
| [0001](0001-soft-delete.md) | Use soft delete for user content and accounts | Accepted |

## Template

```markdown
# NNNN. Title

- **Status:** Proposed | Accepted | Superseded by [NNNN](NNNN-title.md)
- **Date:** YYYY-MM-DD

## Context
What problem are we solving? Which constraints matter?

## Decision
What did we decide?

## Consequences
What becomes easier or harder?

## Alternatives considered
Which options were rejected, and why?
```
